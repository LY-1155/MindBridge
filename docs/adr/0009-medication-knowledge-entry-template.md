# 药物知识条目模板与覆盖范围

> **⚠️ v3.3 更新（2026-07-17）**：文中 Tavily fallback 描述"在 RRF 融合后调用"已过时。
> v3.3 不再使用 RRF 融合，fallback 集成点已变化。详见 [RAG-v3.3-设计文档](../RAG-v3.3-设计文档.md)。

medication_knowledge 公有类别的条目格式、深度标准、全部四批覆盖药物清单和实时搜索 fallback。

## 为什么

- **药物信息错一个字可能出事**。这是 8 个公有类别中风险最高的一类，每条必须有可追溯的权威来源。
- **用户问的是具体问题，不需要学术综述**。每条控制在 200-400 字，粒度对齐用户查询意图，避免信息过载。
- **深浅混排不可控**。如果同一类目下有些条目写 500 字深挖 CYP 酶，有些写 100 字简单概述，向量检索会倾向匹配信息量大但未必相关的条目。统一格式消除这个偏差。

## 条目格式

每药 2 条，不做第三条：

### 条目 A：药物概览

| 字段 | 说明 |
|------|------|
| 内容范围 | 适应症、成人用法用量范围、起效时间、停药基本原则、该药在同类药中的突出特点（一句话） |
| 字数 | 200-300 |
| 不包含 | 详细副作用列表（交给 B）、儿童剂量（中国 18 岁以下多未获批）、详细相互作用列表 |
| 语气 | 客观陈述，不评优不推荐 |

### 条目 B：副作用与安全

| 字段 | 说明 |
|------|------|
| 内容范围 | 常见副作用（带发生率：≥10% / 1-10%）、该药专属高危风险（不是 SSRI 通用模板的复制粘贴）、禁忌症（MAOI + 该药特有的）、撤药反应特征（如果有） |
| 字数 | 300-400 |
| 不包含 | 完整的药物相互作用清单（只提最危险的 2-3 个）、过度详细的药理机制 |
| 语气 | 警示但不制造恐慌，注明高风险项的罕见程度 |

### 通用字段

```json
{
  "id": "med_{药名拼音}_{a或b}",
  "title": "中文药名 - 子主题",
  "content": "...",
  "tags": ["药名", "药物类别", "适应症关键词", ...],
  "source": "dayi.org.cn 中国医药信息查询平台"
}
```

### 暂不纳入

- **苯二氮䓬类**（阿普唑仑、氯硝西泮、劳拉西泮）：依赖风险需要单独讨论篇幅
- **第一代抗精神病药**（氯丙嗪、氟哌啶醇等）：已被非典型药取代，仅特定场景使用
- **ADHD 药物**（哌甲酯、托莫西汀）：属不同治疗领域，ADR 9 未覆盖

## 知识库未收录药物的实时搜索 fallback

### 为什么

20 种药物覆盖了抑郁、焦虑、精神病性障碍和双相情感障碍的核心一线用药，但临床实践中用药范围更广——苯二氮䓬类（阿普唑仑、氯硝西泮等）、较新的抗抑郁药（伏硫西汀、阿戈美拉汀）、ADHD 药物等不在知识库中。当用户问到这些药物时，RAG 检索只能空返或误匹配。

### 机制

```
用户查询
  │
  ├─ KnowledgeRetriever.retrieve() 混合检索
  │     │
  │     ├─ HybridRetriever.retrieve()
  │     │     ├─ LLM 分类
  │     │     ├─ Chroma 稠密 + BM25 关键词（分类过滤）
  │     │     ├─ RRF 融合 → top-k 文本
  │     │     └─ ExternalRetriever.search() ← 外部 API fallback
  │     │           │
  │     │           ├─ DrugNameMatcher.detect_drugs() 检测精神科药物名
  │     │           │     ├─ 全部已知 → 不触发
  │     │           │     └─ 存在未知药物 → 触发 Tavily 搜索
  │     │           │
  │     │           └─ Tavily Search API（site:dayi.org.cn 优先）
  │     │                 ├─ 返回 AI 摘要 + 3 条原文片段
  │     │                 └─ 格式化为 markdown 上下文片段
  │     │
  │     └─ 搜索结果追加到 RRF 结果集中，一起返回
  │
  └─ KnowledgeRetriever 返回合并后结果给调用方
```

三层架构（sources.json v4）：

| 层 | 优先级 | 类型 | 说明 |
|----|--------|------|------|
| hospital_private | 1 | 本地 JSONL | 医院脱敏案例（clinical） |
| public_psychology | 2 | 本地 JSONL | 8 类公有知识 |
| external_api | 3 | Tavily HTTP | 实时搜索兜底（药物名感知触发） |

### 药物名检测覆盖

`core/rag/search_fallback.py` 维护 `_PSYCH_DRUG_KEYWORDS` 表，覆盖 50+ 种精神科药物的中文通用名、英文名和常见商品名。涵盖：

- SSRI/SNRI/NDRI/SARI/NaSSA 抗抑郁药（含伏硫西汀、阿戈美拉汀等较新药物）
- 非典型和第一代抗精神病药（含帕利哌酮、齐拉西酮、氨磺必利等）
- 心境稳定剂（含卡马西平、奥卡西平）
- 苯二氮䓬类（含 7 种临床常用）
- Z-drugs 镇静催眠药
- ADHD 药物
- 辅助药物（苯海索、普萘洛尔、加巴喷丁、普瑞巴林等）

已知药物列表从 `medication_knowledge.jsonl` 的 tags 字段自动提取，确保新增条目后自动纳入。

### Tavily API

| 项目 | 值 |
|------|-----|
| 服务商 | [tavily.com](https://tavily.com) |
| 免费额度 | 1000 次/月 |
| 环境变量 | `TAVILY_API_KEY`（`.env` 中配置） |
| 搜索偏好 | `site:dayi.org.cn` 优先，保持与主源一致 |
| 故障处理 | API key 为占位符或网络错误时静默跳过，不影响主链路 |

### 与 ADR 0008 (PubMed) 的关系

ADR 0008 设计的 PubMed 外部 fallback 是**分数阈值驱动**的通用兜底（RRF top-1 score < 0.5 时触发），而 Tavily 药物 fallback 是**药物名感知驱动**的定向补充。二者互补：

- PubMed（通用，未实现）：任何类别查询的低分兜底
- Tavily（已实现）：精神科药物的定向实时检索，仅在检测到知识库未收录药物时触发

## 写法和禁忌

- **不写"可用于以下疾病"的模糊套话**，写具体适应症
- **副作用标注发生率**，不是"常见/偶见"这种模糊词
- **不复制粘贴 SSRI 共性副作用**，B 条目重点写该药的差异点
- **source 可溯源**：每条标 dayi.org.cn，内容来自药品说明书审核页面
- **不提供剂量建议**：只写常规范围，不写"你该吃多少"
- **不评优**：不说"XX 比 YY 更安全"，只说事实差异

## 验证策略：双源交叉

药物类别是所有公有类别中风险最高的一类，单源不可接受。最终采用：

| 层 | 源 | 性质 | 说明 |
|----|-----|------|------|
| 主源 | dayi.org.cn | NMPA 说明书全文，国家中医药管理局认证 + 三甲主任药师审核 | 40 条均基于此 |
| 交叉验证 | WebSearch 聚合 | 不同临床网站/医学平台对说明书数据的引用 | 逐药对比关键数字 |

未采用的源及原因：
- dxy.cn（丁香园）：与 dayi 同为 NMPA 说明书的授权转载，非独立信源
- NICE 指南：UK 政府网站，国内无法直接访问；HTML 为 JS 动态渲染，requests 抓不到正文
- NMPA 官网：政府网站，JS 交互查询，无法程序化抓取
- 中国药典：无公开 API，无电子全文

已验证状态：
- 全部 20 药 40 条已完成双源验证（主源 dayi.org.cn + WebSearch 交叉验证）
- 第一批（舍曲林、氟西汀、帕罗西汀、艾司西酞普兰、文拉法辛、度洛西汀、米氮平）7 药 14 条
- 第二批（西酞普兰、氟伏沙明、安非他酮、曲唑酮）4 药 8 条
- 第三批（奥氮平、喹硫平、利培酮、阿立哌唑、氯氮平）5 药 10 条
- 第四批（碳酸锂、丙戊酸钠、拉莫三嗪、丁螺环酮）4 药 8 条
