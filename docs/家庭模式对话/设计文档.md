# 设计文档：家庭模式对话

## 1. 核心架构：B 前台 + A 后台

真实心理医生（周医生）的操作是分层的：

| 层 | 做什么 | 用户能感知到吗 |
|---|---|---|
| **前台（对话层）** | 问家庭互动、循环提问、症状功能重构 | ✅ 完全感知 |
| **后台（认知层）** | 对照 DSM 标准静默排除/确认、安全计数 | ❌ 感知不到 |

**前台 = FamilySystemAssessor + 周医生 persona prompt**
**后台 = SCIDTracker（完全静默）**

SCID 追踪结果只做两件事：触达安全红线时升级路由；生成精准的知识库检索 query。

## 2. 会话状态模型（SessionMetadata 扩展）

每个会话新增 4 个字段，跨轮累积：

```python
phase: str = "check_in"          # check_in / explore / interpret / intervene
family_members: List[Dict] = []  # [{"role": "孩子", "label": "", "noted_at": "..."}]
working_hypothesis: Optional[str]  # "孩子的症状可能承担了转移家庭冲突的功能"
scid_flags: Dict[str, Any]      # {"GAD": {"criteria_met": ["irritability"], "count": 1}}
```

### 4 阶段对话弧（对应周医生的临床流程）

| 阶段 | 触发 | 行为指引 |
|---|---|---|
| **check_in** | 前 4 轮 | 建立信任、了解谁最先发现问题、不急于探测 |
| **explore** | 5-12 轮 | 循环提问、探家庭互动模式、识别成员 |
| **interpret** | 13-20 轮 | 试探性重构模式（"听起来你们家似乎……"） |
| **intervene** | 21+ 轮 | 布置小实验、强化改变、复盘连锁反应 |

## 3. FamilySystemAssessor（规则驱动，无 LLM 开销）

输入当前用户文本 + session 状态，输出：

```python
@dataclass
class AssessResult:
    suggested_phase: str        # 阶段推进
    probe_direction: Optional[str]  # 注入 prompt 的探针方向
    hypothesis_update: Optional[str]  # 工作假设更新
    escalation_flag: bool       # 是否升级到危机
    new_family_members: List[Dict]  # 新识别的家庭成员
```

### 关键规则

- **安全红线优先**：检测到自杀/自伤/暴力关键词，或 emotion.risk ≥ 0.7 → `escalation_flag=True`
- **家庭成员识别**：角色关键词表（妈妈/爸爸/孩子/配偶/兄弟姐妹/祖辈）
- **阶段推进**：基于 `message_count // 2` 与阈值表；用户否定假设时退回 explore
- **循环提问引导**：检测到家庭冲突 → 建议问关系（"爸爸觉得妈妈的处理方式怎么样？"）
- **工作假设**：仅 explore/interpret 阶段，且冲突 + 孩子 + 多成员时才生成

## 4. SCIDTracker（完全静默，关键词规则）

对照 DSM-5 标准，覆盖 4 类障碍：

| 障碍 | 覆盖 criteria | 阈值 |
|---|---|---|
| **MDD** | 9 条（情绪低落/快感缺失/食欲/睡眠/精神运动/疲劳/自责/注意力/自杀意念） | ≥5 且含核心症状 |
| **GAD** | 7 条（过度担心/坐立不安/疲劳/注意力/易怒/肌肉紧张/睡眠） | ≥3 |
| **Panic** | 13 条（心悸/出汗/发抖/呼吸急促/窒息/胸痛/恶心/头晕/发麻/失实感/失控/濒死感） | ≥4 |
| **PTSD** | 4 条（闯入/回避/负性认知/高唤醒） | ≥4 |

### 风险升级规则

```python
RISK_DISORDERS = {
    "MDD": ["death_si"],           # 自杀意念 → 升级 crisis
    "Panic": ["fear_dying", "fear_losing_control"],  # 濒死感/失控 → 升级 crisis
}
```

### 精准检索 query

达到阈值时生成如 `"抑郁症 家庭治疗 CBT 行为激活 青少年 循证心理治疗 中文 临床指南"`，替代原 user_text 做 RAG 检索。

## 5. 周医生 persona（prompt 注入）

### 世界观
- 症状是沟通，不是疾病
- 问题是建构的
- 觉察是改变的前提
- 一个人的改变会带动全家

### 语言规则
- **绝对不用**：DSM 标签（"抑郁症"→"心情不好"）、学术术语（"灾难化思维"）、套话共情（"我理解你"）
- **必须用**：对方自己的词、口语化中文、2-3 句内的节奏
- 对方纠正时立刻接受

### 技术偏好
- **循环提问**："爸爸觉得妈妈这样的处理方式怎么样？"
- **0-10 量表**：把主观状态量化
- **症状功能重构**："孩子这次'生病'好像也有它的意义……"
- **假设试探**："听起来你们家似乎有一个循环……是这样吗？"

### 自曝素材
- 适度分享个人经历正常化对方体验（不用编新的，用预置的几条）

## 6. 跨轮状态：内存缓存 fallback

原 `SessionManager.get_session()` 在 `USE_DATABASE=false`（或 Redis/MySQL 不可用）时每次返回**全新实例**，导致多轮状态丢失（连对话历史都不进 prompt）。

**修复**：新增模块级 `_memory_sessions` dict —— 有存储时走 Redis/MySQL，存储不可用时复用内存实例。生产环境（有 DB）不受影响。
