# 数据库备份策略

> Gap #18 — 上线前确认阿里云 RDS 自动备份策略已启用

## 一、备份对象总览

| 对象 | 存储位置 | 备份方式 | RPO 目标 | 保留期 |
|------|----------|----------|----------|--------|
| MySQL 全量数据 | 阿里云 RDS | RDS 自动备份 + 日志备份 | < 1 小时（binlog） | 30 天 |
| `ENCRYPTION_KEY` | 环境变量 | 密码管理器 / 1Password / 阿里云 KMS | 手动备份一次 | 永久 |
| Redis 数据 | Docker volume `redis_data` | RDB 持久化 + AOF（可选） | 可接受丢失 | 7 天 |
| Alembic 迁移记录 | 数据库内 `alembic_version` 表 | 随 RDS 备份 | — | 随 RDS |
| TLS 证书 | 阿里云 SSL 证书管理 | 自动续期 | — | — |

## 二、RDS 自动备份配置（上线前必须逐项确认）

登录 [阿里云 RDS 控制台](https://rds.console.aliyun.com/) → 实例列表 → 目标实例 → 备份恢复 → 备份设置：

### 2.1 数据备份

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 数据备份开关 | **开启** | 必须开启 |
| 备份周期 | **每天** | 至少每天一次全量备份 |
| 备份时间窗口 | **凌晨 02:00-06:00** | 业务低峰期 |
| 全量备份保留天数 | **30 天** | 如需更长可设 60 天 |
| 备份方式 | **物理备份**（推荐） | 比逻辑备份恢复更快 |
| 单库备份 | 建议开启，指定 `prism_db` | 减少备份大小，加快恢复 |

### 2.2 日志备份（Binlog）

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 日志备份开关 | **开启** | 支持恢复到秒级 |
| Binlog 保留时长 | **10 天** | 与全量备份配合 |
| binlog_format | ROW | RDS 默认，不要改 |

### 2.3 异地备份（强烈推荐）

| 配置项 | 推荐值 |
|--------|--------|
| 异地备份 | **开启** |
| 备份地域 | 与主实例不同可用区或地域 |

### 2.4 备份加密

勾选"备份文件加密"（使用阿里云 KMS 托管密钥，或 BYOK 自定义密钥）。

## 三、RPO/RTO 验证标准

| 指标 | 目标 | 验证方式 |
|------|------|----------|
| RPO（数据丢失窗口） | < 1 小时 | 查看 binlog 备份延迟 |
| RTO（恢复时间） | < 2 小时 | 至少一次恢复演练 |
| 备份完整性 | 100% | 随机抽样恢复验证 |

## 四、ENCRYPTION_KEY 备份（关键！）

数据库备份文件中 `messages.content`、`emotion_records.context`、`safety_flags.matched_terms` 三列是 **AES-256-GCM 密文**。如果没有 `ENCRYPTION_KEY`，恢复后的数据无法解密。

### 安全存储要求

1. **不得** 与数据库备份存储在同一位置
2. **不得** 存储在代码仓库或 `.env` 文件中（确认 `.env` 不入 git）
3. 推荐方式：
   - 阿里云 KMS（Secrets Manager） — 与 RDS 同账号
   - 1Password / LastPass 团队共享 Vault
   - 离线纸质备份（密钥信封，物理锁定存放）

### 生成新密钥（如果需要轮换）

```bash
openssl rand -base64 32
```

注意：密钥轮换后，旧数据需要重新加密或保留旧密钥用于解密。

## 五、恢复演练清单（上线前至少执行一次）

### 5.1 恢复目标

- [ ] 从 RDS 备份创建一个新（临时）实例
- [ ] 验证所有 7 张表数据完整（users, credentials, sessions, messages, emotion_records, safety_flags, scale_screenings）
- [ ] 使用 `ENCRYPTION_KEY` 解密 `messages.content` 抽样验证可读
- [ ] 验证 `alembic_version` 表存在且迁移版本号正确
- [ ] 连接应用（指向恢复实例），执行冒烟测试：
  - 用户登录
  - 发送一条消息
  - 查看历史消息

### 5.2 恢复步骤概览

```bash
# 1. 阿里云 RDS 控制台 → 克隆实例（从备份集创建）
# 2. 获取新实例连接地址后，修改 .env：
#    MYSQL_HOST=<恢复实例地址>
# 3. 启动应用：
docker compose -f docker/docker-compose.yml up -d therapy-agent
# 4. 冒烟验证后删除恢复实例
```

## 六、Redis 数据备份（低优先级）

Redis 主要用于速率限制计数和会话缓存，丢失不影响核心数据。

当前配置（`docker/docker-compose.yml`）：
```yaml
redis:
  volumes:
    - redis_data:/data
```

Redis 默认 RDB 持久化策略（`save 3600 1 300 100 60 10000`）即可满足需求。不需要额外备份方案。
